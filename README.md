# Homebrew tap: Dikec DPI

```bash
brew tap dikeckaan/dikecdpi
brew trust dikeckaan/dikecdpi   # Homebrew 7+: tap'i bir kez onaylayın
brew install --cask dikec-dpi   # macOS menü çubuğu uygulaması
brew install dikecdpi           # komut satırı aracı
```

Arka planda çalıştırmak için: `brew services start dikecdpi`

Proje: https://github.com/dikeckaan/DikecDPI
